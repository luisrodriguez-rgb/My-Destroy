Al incorporar un recurso, guardar procedencia, archivo seleccionado, versión o fecha de descarga, modificaciones y licencia incluida. Conservar el aviso de copyright y OFL junto a la fuente. La licencia de estos recursos no establece por sí sola la licencia del código del proyecto.

Usar tipografía legible para instrucciones y reservar la tipografía pixel para tamaños adecuados. Evaluar juntos personaje, fondo e interfaz para evitar densidades de píxel incompatibles.

El sonido puede generarse localmente para la primera prueba. Si se usa un archivo externo, registrar también su procedencia y licencia concreta.
