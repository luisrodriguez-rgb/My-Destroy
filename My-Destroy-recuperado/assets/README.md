# Recursos artísticos preparados

Esta carpeta contiene una selección de fuentes para la dirección visual de My-Destroy. No es una colección que deba cargarse entera en el juego: se seleccionarán los sprites necesarios y se exportará un atlas de producción.

| Carpeta | Autor | Licencia | Uso previsto |
| --- | --- | --- | --- |
| `sources/kenney-1bit-platformer` | Kenney | CC0-1.0 | Siluetas y piezas técnicas de 16 × 16; tintado y selección para escenarios |
| `sources/kenney-pixel-ui` | Kenney Vleugels, con ayuda de Lynn Evers | CC0-1.0 | Iconos y detalles de paneles; tiles de 16 × 16 con separación de 2 px |
| `sources/pixelify-sans` | The Pixelify Sans Project Authors | OFL-1.1 | Títulos y etiquetas breves; conservar el aviso de licencia al distribuir |

Los packs de Kenney se descargaron desde el mirror `ETdoFresh/kenney.nl`, revisión `45df48c4d45f8716216b1a9e22df0b69cd9f5932`. Se conservaron las licencias individuales de cada pack, que expresamente permiten proyectos personales y comerciales. La web original de Kenney no pudo consultarse por la política de red del entorno. El mirror no es la página oficial del autor.

La fuente se obtuvo del repositorio oficial `google/fonts`, revisión `1d0e46c7933245c8180fe83e47917961c913bbdb`, con su licencia OFL. Los archivos descargados no fueron modificados. `manifest.json` registra URL exacta, revisión, tamaño y SHA-256 de cada uno.

## Créditos preparados

- **1-Bit Platformer Pack** — Kenney, <https://kenney.nl>, CC0-1.0. La atribución no es obligatoria según el aviso del pack; se conserva por reconocimiento y trazabilidad.
- **Pixel UI Pack** — Kenney Vleugels / Kenney, con ayuda de Lynn Evers, CC0-1.0.
- **Pixelify Sans** — The Pixelify Sans Project Authors, OFL-1.1. Ver `sources/pixelify-sans/OFL.txt`.

El nombre y la interfaz de My-Destroy, las formas de armas de la lámina de dirección y la composición de ejemplo son trabajo propio del proyecto. No se descargaron sprites, armas ni fondos del juego Destroy Any Website.

## Fuentes pendientes y alternativas

- <https://www.spritefusion.com/tilesets> y <https://www.spritefusion.com/pixel-art-gallery>: acceso bloqueado desde este entorno. No se verificaron las fichas, autores o licencias; no se importó contenido de esas páginas. La visibilidad pública de una imagen no establece sus condiciones de reutilización.
- <https://kenney.nl/assets/pixel-platformer>: candidato para un estilo más colorido, aún no elegido ni importado. Evitar mezclarlo sin adaptar con la dirección técnica elegida.
- <https://github.com/Brackeys/first-game-in-godot/tree/388257461dbd07b1e5020270c72fca48b30c493d>: su README declara el contenido de dominio público y uso comercial permitido; se inspeccionó. Personaje de fantasía y tiles naturales: reserva, no importados por no encajar con el tema elegido.
- <https://github.com/Spyridon-Pikoulas/godot-explosion-fx-free>: el README consultado declara CC BY 4.0 y exige crédito. Reserva para evaluar VFX; no importado ni seleccionado como dependencia.
- OpenGameArt e itch.io: catálogos para futuras necesidades. Revisar la ficha de cada recurso, no aplicar una licencia global al sitio.

Antes de incorporar otro pack: guardar su licencia específica y procedencia, revisar la hoja real y sus animaciones, registrar las modificaciones y comprobar escala, paleta, contraste y pivotes en la escena de prueba.
